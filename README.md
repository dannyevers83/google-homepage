# Google Homepage Recreation

A responsive recreation of the Google homepage built with HTML and CSS. This learning project helped me practice page structure, layout, and styling.

## Live Demo

[View the live project](https://danny-google.netlify.app/), hosted on Netlify.

## Features

- Navigation links and a profile image
- Search input with microphone and camera icons
- Google Search and I'm Feeling Lucky buttons
- Responsive navigation and footer layouts
- Hover and focus effects

This is a visual recreation. Search, voice search, and image search are not implemented, and some links use placeholder destinations.

## Built With

- **HTML5** — page structure
- **CSS3** — styling, spacing, and typography
- **Flexbox** — page layout and alignment
- **CSS Grid** — icon alignment
- **Media queries** — layout adjustments for different screen sizes
- **Google Fonts** — typography
- **Font Awesome** — icons

## Getting Started

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` with the Live Server extension.

No build step or package installation is required. An internet connection is needed to load the external fonts and icons.

## What I Practiced

- Structuring a page with HTML landmarks such as `header`, `nav`, `main`, and `footer`
- Positioning and aligning elements with Flexbox
- Adapting layouts with a mobile-first media query
- Styling buttons, links, and input fields
